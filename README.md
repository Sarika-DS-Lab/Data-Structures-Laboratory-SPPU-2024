# Data Structures Laboratory
## PCC-204-COM | SPPU 2024 Pattern | Python

Welcome to the **Data Structures Laboratory** repository.

This repository contains Python programs and supporting learning material for the Data Structures Laboratory as per the SPPU 2024 Pattern.

The purpose of this repository is to help students understand, execute, test and modify Data Structures programs using Python and Visual Studio Code.

# 🎯 Course Objectives

The Data Structures Laboratory aims to:

1. Provide hands-on experience with basic and advanced data structures.
2. Understand various data searching and sorting methods with their advantages and limitations.
3. Apply appropriate data structures for solving real-world problems.

---

# 🎓 Course Outcomes

After completing the laboratory work, students should be able to:

### CO1
Analyze basic searching and sorting algorithms to solve problems and evaluate their efficiency in different scenarios.

### CO2
Make use of stack and queue concepts to solve given problems.

### CO3
Demonstrate various types of linked lists.

### CO4
Demonstrate basic operations on trees and graphs and determine minimum spanning solutions.

### CO5
Apply a suitable data structure for solving application-based problems.
